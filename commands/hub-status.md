---
description: Show who holds the shared resources, who waits, and requests waiting for a person (Unreal Agent Hub)
---

Call the `hub_status` tool of the unreal-agent-hub MCP server (or run `hub status` in a shell) and summarize it
in a few lines: busy resources with their holder and how long, the queue in order, and any handover request
waiting for a person. Do not take or release anything.
